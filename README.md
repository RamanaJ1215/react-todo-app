# ReactJS Todo List

A simple and modern Todo List application built with React, Vite, and Bootstrap.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks (from both active and completed lists)
- Responsive UI with Bootstrap styling

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/reactjs-todo.git
   cd reactjs-todo
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

### Running the App

Start the development server:
```sh
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```sh
npm run build
```

### Linting

```sh
npm run lint
```
